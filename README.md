# Odin Landing-page

This is my solution for the Landing Page project from [The Odin Project](https://theodinproject.com).

## 🚀 Live Demo
[View Live Demo](https://arefat21.github.io/landing-page/)

## 🛠 Built With
- **HTML5**: Structured with semantic elements for better accessibility.
- **CSS3**: Styled using Flexbox, custom layouts, and a global box-model reset.
- **Git/GitHub**: Version control and project hosting.

## What I Learned

During this project, I strengthened my understanding of:
*   **Flexbox**: Using `justify-content`, `flex-direction` and `align-items` to create complex layouts and center content.
*   **CSS Architecture**: Organizing my styles to reduce repetition by grouping classes.
*   **Git Workflow**: Managing a project from start to finish with regular commits and pushes.
*   **Box Model**

## ⚡ Challenges

1. **Consistent Indentation**: The most difficult part was ensuring the Header (logo/links) and the Hero content below it    started at the exact same vertical line. 
I solved this by using a shared container class with a fixed max-width and margins.

2. **Flexible Hero Visuals**: One of the challenges was getting the Hero image placeholder to stretch to the full height of the text content while keeping the text centered inside it. I solved this by treating the placeholder as both a flex item (child) and a flex container (parent).

3. **DRY (Don't Repeat Yourself)**: Initially, I had significant CSS repetition. I overcame this by refactoring my code.
